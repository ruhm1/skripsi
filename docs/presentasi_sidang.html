Preprocessing Data

  • Drop 19 kolom kosong + kolom tidak relevan
  • Parse usia dari format teks ke numerik
  • Split tekanan darah: sistolik / diastolik
  • Ekstraksi keluhan sesak dada dari teks bebas
  • Label target: ICD-10 kode I10-I79 (kardiovaskular)
  • Penanganan anomali: BMI=0, TD=0/0, BMI>100000
  • Hasil: 31.638 → 27.817 rekord bersih

Analisis & Pembahasan

Kekuatan

  • Recall 79.83% — deteksi dini efektif
  • Tidak overfitting (gap 0.002)
  • Explainable — decision path transparan
  • Data riil 27.817 pasien
  • Cross-validation stabil

Keterbatasan

  • Precision rendah (24.25%) — banyak FP
  • Hanya 6 fitur prediktor
  • Label retrospektif (bukan prospektif)
  • Tidak ada data kolesterol
  • Single-center (RSU Aulia saja)

Kesimpulan

  • Aplikasi CARDIOCARE berhasil dibangun sebagai SPK deteksi dini risiko penyakit jantung berbasis web
  • Model Decision Tree menghasilkan Recall 79.83% dan ROC-AUC 0.7927
  • Usia merupakan prediktor paling dominan (61.1%)
  • Seluruh halaman menggunakan data riil 27.817 pasien — tanpa data dummy
  • Decision path memberikan transparansi keputusan untuk tenaga medis
  • Sistem siap digunakan sebagai alat bantu skrining di RSU Aulia

Saran Pengembangan

  • Penambahan fitur klinis: kolesterol, gula darah, riwayat keluarga
  • Implementasi SMOTE untuk penanganan class imbalance
  • Integrasi dengan SIMRS (Sistem Informasi Manajemen RS)
  • Validasi prospektif di lingkungan klinis nyata
  • Pengembangan modul mobile untuk dokter
  • Multi-center study untuk generalisasi model
