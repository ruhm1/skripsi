EXECUTIVE SUMMARY
CARDIOCARE — Sistem Pendukung Keputusan Deteksi Dini Risiko
Penyakit Jantung Berbasis Web Menggunakan Algoritma Decision Tree
RSU Aulia, Jakarta Selatan
======================================================================

LATAR BELAKANG
Penyakit jantung merupakan penyebab kematian utama di Indonesia.
RSU Aulia memiliki visi transformasi digital 2026 dan potensi besar
untuk implementasi sistem cerdas. Deteksi dini yang cepat dan akurat
dapat menekan angka mortalitas secara signifikan.

TUJUAN
Membangun aplikasi SPK berbasis web untuk membantu tenaga medis
RSU Aulia dalam melakukan deteksi dini risiko penyakit jantung,
menggunakan algoritma Decision Tree yang transparan dan mudah
dipahami.

METODE
- Dataset: 27.817 rekord pasien RSU Aulia (setelah data cleaning)
- Fitur: usia, gender, keluhan sesak dada, BMI, sistolik, diastolik
- Algoritma: Decision Tree (entropy, max_depth=7, balanced)
- Arsitektur: Flask (backend) + HTML/CSS/JS (frontend)
- Evaluasi: Accuracy, Precision, Recall, F1, ROC-AUC

HASIL MODEL
+--------------------+----------+
| Metrik             | Nilai    |
+--------------------+----------+
| Accuracy           | 65.89%   |
| Precision          | 24.25%   |
| Recall             | 79.83%   |
| F1-Score           | 37.19%   |
| ROC-AUC            | 0.7927   |
| Overfitting Gap    | 0.002    |
+--------------------+----------+

FEATURE IMPORTANCE
1. Usia — 61.1% (prediktor dominan)
2. BMI — 12.8%
3. Sistolik — 12.3%
4. Gender — 7.8%
5. Diastolik — 5.1%
6. Sesak/Nyeri Dada — 0.9%

PERBANDINGAN MODEL
+---------------------------+--------+--------+--------+-------+
| Model                     | Acc    | Prec   | Recall | AUC   |
+---------------------------+--------+--------+--------+-------+
| Decision Tree (Baseline)  | 65.89% | 24.25% | 79.83% | 0.793 |
| Decision Tree (Tuned)     | 64.11% | 24.13% | 85.65% | 0.781 |
| Random Forest             | 70.63% | 27.49% | 80.68% | 0.823 |
| Gradient Boosting         | 87.19% | 46.09% |  7.53% | 0.828 |
+---------------------------+--------+--------+--------+-------+

Decision Tree dipilih karena explainability tinggi dan recall
memadai untuk konteks deteksi dini.

FITUR APLIKASI
1. Dashboard monitoring dengan data riil 27.817 pasien
2. Prediksi risiko jantung berbasis Decision Tree
3. Data pasien dengan search, filter, dan pagination
4. Rekam medis elektronik (EMR)
5. Laporan statistik + export CSV/Excel/PDF
6. Pemeriksaan EKG dengan animasi realtime
7. Alur keputusan (decision path) transparan

KONTRIBUSI
- Alat bantu skrining dini untuk tenaga medis RSU Aulia
- Transparansi keputusan melalui decision path
- Integrasi data riil rumah sakit
- Siap demonstrasi dan deployment
